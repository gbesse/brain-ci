# Security

Report vulnerabilities privately through GitHub's repository security advisory flow.

Brain CI executes the adapter command supplied in the local config with the user's OS privileges. Treat configuration as trusted code. The runner checks citation paths and quotes, rejects working-wiki symlinks, and uses Git file reads for the baseline; it is not a sandbox for an untrusted adapter or repository.

The TypeSafe judge sends question answers and the expected answer to a hosted service. Reports include those answers and their citations. Keep private brains, reports, and API keys out of public repositories. `.env` is ignored by this repository.
